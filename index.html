Yeni mezun bir bilgisayar mühendisi olarak, .NET teknolojileri ve modern web geliştirme konularında tam donanımlı bir Full Stack geliştirici olma yolunda emin adımlarla ilerliyorum. Özellikle ASP.NET Core, MVC mimarisi, Entity Framework ve SQL Server kullanarak gerçek dünya projelerinde deneyim kazandım. Katmanlı mimari, RESTful API geliştirme, kullanıcı yönetimi ve ödeme entegrasyonu gibi konularda pratik tecrübeye sahibim. Aynı zamanda frontend tarafında HTML, CSS, JavaScript ve React.js gibi teknolojilerle kullanıcı dostu arayüzler geliştiriyorum. Bitirme projem kapsamında MERN stack ile lastik.com.tr klonunu geliştirerek, modern bir e-ticaret altyapısını uçtan uca kurma becerisi kazandım. Staj sürecimde ise yapay zeka temelli projelerde görev alarak Dialogflow ve ChatGPT API gibi teknolojilerle chatbot geliştirdim. Bu sayede farklı teknolojileri entegre etme ve çözüm üretme yetkinliğimi artırdım. Yenilikçi teknolojilere hızlı adapte olabilen, takım çalışmasına yatkın ve analitik düşünme becerisi yüksek bir yazılım geliştirici olarak, .NET ekosisteminde uzmanlaşmayı ve değer üreten projelerde yer almayı hedefliyorum.
